# 中科大本科课程资料导航

*这是一个给中科大本科生找学习资料的网站。*

*输入课名或课号，就能看到这门课有哪些往年试题和解析、作业与小测、学习资料、教材与参考书，以及大作业和考核作品。*

*准备复习时，可以按考试年份找题；想看看某个学科有哪些课程可参考，可以先按学科浏览，再筛出已有资料的课。*

## 在线使用

**[打开中科大本科课程资料导航](https://twinjades.github.io/USTC_Study_Materials_Navigation/)**

## 怎么找资料

1. **找课程**：输入课名或官方课号，也可以按课程类别、学科、资料类型和收录状态缩小范围。同名或近似课程可以用课号区分。
2. **找试题**：选择「试题与解析」后按年份筛选。点进课程，可查看已知学年或年份、期中或期末、是否有解答等信息。
3. **看原始出处**：课程详情的简洁模式也保留已登记的原始页面，有独立文件直链时可另点「打开文件」。需要核对作者、其他来源或收录依据时，切换到详细模式。

标记「需登录」的评课社区资料会链接到原点评。请到评课社区登录后从原帖下载；本站不提供这些附件的下载直链。

详细模式会显示收录依据，并在已取样的公开下载直链下显示文件大小、取样日期和 SHA-256。只有预览页或目录的入口不显示哈希。部分条目使用 AI 辅助查阅来源，以所列原始证据为准。

目录覆盖 **2025 秋、2026 春、2026 夏、2026 秋**的 **1,184 门本科课程**，其中 **374 门**已收录 **2,293 条**资料。「暂未收录」表示目前索引里还没有该课程的资料。

## 让 Agent 帮你查

> 我想找「课程名或课号」的「资料类型、年份或卷别」。请先查https://twinjades.github.io/USTC_Study_Materials_Navigation/data/agent/index.json ，再打开data/agent/courses/，把找到的公开文件下载到当前工作区，并附上原始出处。如果有多个可能的课程或文件，请先列出选项问我，确认后再下载；只有原始页面而没有可下载文件时，请告诉我。

## 推荐资料来源

知道值得收录的公开资料页、目录或资料库？请填[推荐资料来源表单](https://github.com/TwinJades/USTC_Study_Materials_Navigation/issues/new?template=suggest-source.yml)，不需要改代码。熟悉 Git 的读者也可提 Pull Request。我们核对后再收录，可以按你的意愿公开致谢。
